# Kickabout

Top-down arcade soccer against CPU players. No build step: open `index.html` in a browser.

- Move: WASD / arrows. Kick: Space / X. Sprint: Shift. Pause: P. Menu: Esc.
- Touch: drag the left half to move, tap the right half to kick.
- 1v1 to 4v4, three CPU difficulty levels, or watch CPU vs CPU.
