# Kickabout

Top-down arcade soccer against CPU players. No build step: open `index.html` in a browser.

- Move: WASD / arrows. Kick: Space / X. Boost: Shift or B (three bursts, 5s recharge). Hold kick; move across the ball as you kick to curve it. Mouse: left kicks, right boosts. Camera: C (follow or full pitch). Pause: P. Menu: Esc.
- Touch: drag the left half to move, right side lower half kicks, upper half boosts.
- 1v1 to 5v5, three CPU difficulty levels, or watch CPU vs CPU.
